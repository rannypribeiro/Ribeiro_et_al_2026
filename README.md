This repository accompanies the preprint “Repeated regeneration prolongs the juvenile stage and extends lifespan in the annelid Platynereis dumerilii.”

The study investigates how repeated posterior amputation and regeneration affect developmental progression, reproductive maturation, regenerative competence, and lifespan in P. dumerilii, describing a phenomenon termed the Highlander effect.

This repository contains supporting data, analysis scripts, and protocols used to generate the results and figures presented in the manuscript.
